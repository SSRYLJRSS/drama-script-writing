# 剧本风格系统（底层模型）

> 这份文件不教你"怎么写"，教你"观众怎么看"。
> 理解了AI短剧观众的认知节奏，所有规则都能自己推导出来。
> **题材不限**：压抑型、讴歌型、反转型都能写，但每个题材的"情绪引擎"不同——见下文"情绪基调定位"。

---

## 底层原理：AI短剧观众的认知节奏

AI短剧观众不是读者，是刷视频的人。他们的特点：
- **3秒决定留不留**：序幕第一个画面/第一句台词定生死
- **注意力是消耗品**：每句废话对白都在消耗耐心，没有新信息就划走
- **先被冲击再愿意看**：必须先被一个画面或事件炸到，才愿意跟进后续
- **对话是唯一引擎**：信息只能通过角色之口传递，旁白和独白=观众退出
- **情绪是导航**：不是跟着逻辑走，是跟着"虐不虐""气不气""痛不痛"走

---

## 四个认知时刻

### 时刻一：序幕（前5行）

**观众状态**：不认识你，没有耐心，随时划走。
**你需要给**：全剧最大冲击力的那一刻，直接甩到脸上。

序幕必须是全剧最抓人的一幕。不做背景介绍，不做人物铺垫，不做时间线交代。把最有冲击力的事件直接呈现——跳楼、判决、扇耳光、密谋、冲突最激烈的那一秒。

**序幕铁律**：
1. **开场即高潮**：跳楼就先跳，判决就先判，扇耳光就先扇。不要从"某天早上"开始
2. **一句台词定生死**：序幕第一句台词必须携带核心矛盾。"妈妈我爱你"后跳下，比"今天又是新的一天"强一万倍
3. **不铺垫**：序幕不需要让观众理解前因后果，只需要让他们被震住，然后想知道"为什么"
4. **可以闪前**：把结局或最惨的一幕放到序幕，再用后续幕次回溯。闪前≠剧透，闪前=钩子

### 时刻二：每幕推进

**观众状态**：被序幕抓住了，但耐心在递减。
**你需要给**：每幕一个新场景、新冲突、新信息。说完就走。

**每幕只干一件事**：抛出一个冲突或推进一个事实。信息说完立刻切场景。观众一旦觉得"这段我刚才看过了"就会划走。

**幕长度铁律**：
1. **序幕 15-20 行（加长演足，把最狠的一幕演透）**，每幕 ≤20 行：只取冲突最尖的那一刻
2. **不灌水**：不写过渡段、不写铺垫段、不写"第二天早上"这种时间交代
3. **场景切换=信息切换**：每幕换一个场景，每个新场景必须带来新信息

### 时刻三：对话交锋

**观众状态**：在看两个人说话，想知道他们之间会发生什么。
**你需要给**：一人一句快速交锋，每句都是"点"。

**对话铁律**：
1. **一人一句**：不写大段独白。A说一句，B回一句，A再怼回来。节奏要快
2. **每句都是点**：具体数字、具体行为、具体细节。不写"成绩不好"，写"英语53，你同桌91"
3. **没有废话对白**：不写"你觉得呢""我也不知道""嗯"这种填充物（除非"嗯"本身就是一种压抑的回应）
4. **口语化**：像人说话，不像写作文。"不考零蛋就行"比"你的成绩还有很大提升空间"有冲击力
5. **允许适当粗口**：增加真实感。"跟你爸一个德行""装死"
6. **角色没有完整表白**：真实人在冲突中不会说长话，都是短句、碎句、被打断的话
7. **对话有权力方向**：不是平等交流，是有高低的信息博弈。一方在追问/施压，另一方在回避/承受

### 时刻四：结尾

**观众状态**：已经看完了全剧，情绪在最高点。
**你需要给**：一个让他带着情绪离场的画面或一句话。

**结尾铁律**：
1. **不给爽文结局**：留"未完成的正义"或"无法弥补的损失"
2. **用画面收束**：无人机视角、同一扇窗、黑屏字幕。不用博主金句
3. **字幕串联真实案例**：用2-4个真实事件的简短陈述打底，最后一句话点题但不煽情
4. **不总结不说教**：不用"愿每个孩子都被温柔以待"这种收尾
5. **让观众带着情绪离场**，不是带着"结论"离场

## 基调原则：情绪到底（按题材定位）

**总原则**：观众的眼泪/愤怒/敬意必须在结尾达到峰值。题材决定情绪引擎，动笔前先选基调。

### 压抑型：压抑到底

压抑不是"全程悲伤"，是"全程没有出口"。

**压抑的构成**：
- **施暴者不觉得自己在施暴**："我都是为你好"——这句话每次出现都是一次施压，但说的人觉得是爱
- **受害者无法反抗**：不是不想反抗，是反抗的通道全被堵死
- **旁观者在帮施暴者**："孩子太脆弱""跟你没关系""我们小时候挨打比这狠多了"——整个系统都在说"为你好"没错
- **没有一个人在事前接住受害者**——所有"关心"都发生在事后

**压抑的反面不是"快乐"，是"出口"**：
- 温情线=出口（道歉、被安慰）→ 砍掉
- 周全赴死=出口（整理遗物、写长遗书）→ 砍掉
- 正义降临=出口（施暴者醒悟、法律制裁）→ 砍掉或弱化
- 控诉式遗言=出口（大段控诉）→ 砍掉，换成一句话

### 讴歌型：讴歌到底（伟人/英雄/正能量题材）

**讴歌不是宣传稿**。讴歌的情绪引擎=**反差**：牺牲越大、主角越不当回事；时代越难、做成的事越大。观众落泪是因为"伟大者从不觉得自己伟大"，不是因为有人在说教。

**讴歌的构成**：
- **时代做反派**：没有恶人，反派是一穷二白、死亡率逼近100%、无药无械。主角对抗的是"时代"
- **反差是引擎**：100%死亡率 vs 5%死亡率的数字反差；个人手术刀 vs 千万儿童的取舍反差；被辜负 vs 仍在坚守的反差
- **敬意延迟释放**：生前被低估/被忽略，身后才被看见——迟到的敬意最催泪
- **牺牲轻描淡写**：主角说最重的话用最轻的口气（"就我自己孩子，我就拿他一下子吧"）——这句式是讴歌型金句模板
- **结尾必须"功成"**：压抑型留"未完成的正义"，讴歌型必须给"完成感"——英雄做成了一件事，哪怕代价巨大。字幕串联真实数据（死亡率90%→30%、10张床→1.2万医师），最后一句话是致敬不是质问

**讴歌型的"出口"规则与压抑型相反**：
- 温情线=主菜（不是出口，是讴歌的燃料）→ 保留并放大
- 牺牲时刻=必须正面呈现（不是回避，是讴歌的峰值）
- 敬意=必须释放（迟到的敬意是结尾钩子）
- 禁止：说教总结（"愿每个孩子都被温柔以待"式收尾）、官方宣传腔、歌功颂德堆砌形容词。用画面、数字、反差顶情绪

**检验方法**：把讴歌型剧本念给观众听，如果情绪峰值出现在"主角的牺牲/反差"上=对了；如果出现在"讲解员的赞美"上=宣传稿，重写。

### 不同题材的情绪来源

| 题材基调 | 情绪来源 | 情绪峰值时刻 | 最虐/最燃一刻 |
|---------|---------|-------------|-------------|
| 压抑型 | 施暴者不知自己在施暴 | 死后施暴者还在说"为你好" | 施暴者到最后都不知道自己做错了什么 |
| 罗生门型 | 真相永远模糊，双方都"不能就这么算了" | 没有赢家 | 所有人都是受害者 |
| 制度失效型 | 维权通道全堵死，踢皮球链条环环相扣 | 正义来了但远远不够 | 每个环节都说"不归我管" |
| 反转型 | 装逼者被打脸 | 打脸那一秒的台词 | 弱者一句话掀桌 |
| 集体失败型 | 所有人想当领导没人干活 | 最后一句话=嘲讽+无奈+主题 | 群像分裂过程 |
| 漠视型 | 施暴者到最后都不知道自己做错了什么 | 死后所有人帮施暴者开脱 | 帮凶比施暴者更可恨 |
| **讴歌型** | **被辜负者仍在坚守 / 伟大者从不觉得伟大** | **迟来的敬意+主角的无所谓** | **"就我自己孩子，我就拿他一下子吧"** |

**压抑型最压抑的结局**：施暴者到最后都不知道自己做错了什么。
**讴歌型最燃的结局**：英雄做成了那件事，代价巨大，但他觉得值——然后字幕给数据，敬意释放。

## 对话驱动的本质

AI短剧不是话剧，不是小说，不是新闻报道。

- **话剧**：一个人可以独白三分钟。AI短剧不行。
- **小说**：可以用大段旁白描写心理。AI短剧不行。
- **新闻**：可以用叙述者交代背景。AI短剧不行。

**信息只能通过两种方式传递**：
1. **角色对话**：两人以上在场景中说话
2. **动作描写**：括号里几个字（"啪——耳光""掐住脖子顶在墙上"）

**禁止**：自言自语、旁白叙述、大段独白、角色对着空气说话

**检验方法**：把所有对话去掉，如果场景描写本身在"讲故事"=叙述太多了。

---

## 信息密度的本质

每句话都让观众获得新信息。

**五类信息增量**：

| 类型 | 说明 | 示例 |
|------|------|------|
| **数字** | 金额、名次、年龄、时长 | 4000/2800/53/91/76名/600块 |
| **动作** | 具体行为 | 扇耳光、掐脖子、戳额头、站到桌子上 |
| **规则** | 制度/条款 | "考到前20""补习班2800""请假扣80块" |
| **关系** | 人际互动 | "你爸跑了""一个人拉扯你""你跟爸一个德行" |
| **后果** | 直接损失 | "回家再算""你自己看着办""装死" |

**检验方法**：把这句台词换成任何家庭都能说的话（"你要好好学习"），如果还成立=太笼统。

**高密度写法**："我一个月挣4000，给你交2800补习费，你自己算我剩多少"——一句话包含收入、支出、经济压力比例、施压理由。

## 结构是骨架，不是牢笼

四到五幕的结构模板是记忆辅助，不是公式。记住三点：

1. **序幕炸场**：全剧最冲击的一幕前置
2. **每幕只取最尖的那一刻**：不铺垫、不过渡、不灌水
3. **结尾压住**：用画面或一句话收束，留未完成的情绪

幕数根据事件复杂度决定：
- 事件单一、冲突集中：4幕够
- 事件复杂、多视角：5幕
- 事件有时间跨度：5-6幕，但每幕依然极短

### 幕次排列逻辑

**核心原则**：先让观众愤怒于"系统怎么运作"，再看个体被碾压。

如果事件有**产业链/系统性之恶**，幕次排列顺序：

```
序幕  结局前置（毁灭瞬间，台词携带反差暴击）
  ↓
第一幕  系统性之恶（产业链分赃、规则制定者如何害人）
  ↓
第二幕  群像受害（用学生/同事间对话展示群体受害）
  ↓
第三幕  个体被压（主角求救被拒，观众已愤怒再看个体最痛）
  ↓
第四幕  最亲的人补刀（家长/伴侣"为你好"的施压）+ 结构回环
```

**反面教训**：不要把个体冲突（请假被拒）放第一幕——那时系统之恶还没建立，观众还没愤怒，个体悲剧没有根基。
