# 🎬 drama-script-writing · AI短剧剧本撰写 Skill

> **把真实社会热点事件改编成 AI 短剧剧本** —— 多案例糅合、全剧四幕、序幕炸裂、情绪驱动、对话驱动、题材不限。
> 一套完整的 S0→S7 写作流水线，让 AI 像资深编剧一样工作：不写废话、不灌水、不降智、忠于事实。

**An AI Agent Skill that turns real social hot-topic events into AI short-drama scripts — a complete S0→S7 production pipeline with multi-case blending, explosive openings, emotion-driven scenes and dialogue-first writing.**

---

## ✨ 为什么用它

普通 AI 写剧本：平铺直叙、角色单薄、说教结尾、事实全靠编。

用这个 Skill 写剧本：

| 维度 | 普通 AI | 本 Skill |
|------|---------|----------|
| 开头 | 铺垫背景 | **序幕炸裂**：第一句台词携带核心矛盾，3秒抓住观众 |
| 结构 | 想到哪写到哪 | **全剧四幕**：序幕（15-20行演足）+ 推进 + 反转 + 结尾压住 |
| 案例 | 写一个人 | **多案例糅合**：多个真实案例融成一人设，字幕串联真实案件打底 |
| 台词 | 长篇大论 | **对话驱动**：一人一句快速交锋，每句都是"点"，禁独白旁白 |
| 事实 | 凭印象编 | **忠于事实**：判决/数据/案件定性不编不改，法律事实权威核验 |
| 题材 | 只会一种 | **题材不限**：压抑型 / 讴歌型 / 反转型 / 罗生门型，动笔前先定情绪基调 |
| 学习 | 每次从零 | **自动进化**：你每次改稿，AI 自动对比学习，经验写入规则 |

## 🚀 快速上手（三步）

### 第一步：建项目文件夹

```
你的项目目录/
└── 某事件/                     ← 项目名，随便起
    └── 初步资料.md              ← 写下要改编的事件（链接或文字描述都行）
```

### 第二步：告诉 AI 开工

> "帮我写一个剧本。事件是 XX，初步资料在 `某事件/初步资料.md`，工作目录是 `某事件/`。"

### 第三步：走 7 步流程

```
S0 读取初步资料 + 建目录
  ↓ ← 等你确认
S1 发散搜索选题（至少5-8个案例，出选题卡）
  ↓ ← 等你确认
S2 资料收集 + 冲突点提炼
  ↓ ← 等你确认
S3 故事线设计（序幕 + 四幕结构）
  ↓ ← 等你确认
S4 写剧本（交付前 AI 先自检）
  ↓ ← 等你确认
S5 自检修改
  ↓
S6 自我学习（你改过的版本 AI 自动学习）
```

**每一步 AI 输出后都会停下来等你确认**，你说"就这样""开始""确认"它才进下一步。不跳步、不连做、不自己发挥。

## 🎭 四种题材，一种内核：调动情绪

| 题材基调 | 情绪来源 | 情绪峰值 | 适用事件 |
|----------|---------|---------|---------|
| **压抑型** | 施暴者不知自己在施暴 / 出口全被堵死 | 死后施暴者还在说"为你好" | 施暴-毁灭、制度失效、漠视型事件 |
| **讴歌型** | 被辜负者仍在坚守 / 伟大者从不觉得伟大 | 迟来的敬意 + 主角的无所谓 | 伟人传记、平民英雄、时代脊梁 |
| **反转型** | 装逼者被打脸、弱者翻盘 | 打脸那一秒的台词 | 网红塌房、嚣张者被制裁 |
| **罗生门型** | 真相永远模糊，双方都"不能就这么算了" | 没有赢家，所有人都是受害者 | 争议事件、各执一词事件 |

动笔前 AI 会先和你确认题材基调，**压抑到底 / 讴歌到底 / 打脸到底**，情绪峰值必须出现在结尾。

## 📋 核心规则速查

| 规则 | 说明 |
|------|------|
| 每步等确认 | AI 不能自动连做，你说"确认"才下一步 |
| 所有产出双输出 | 选题卡/故事线/剧本 → ①保存文件 ②对话完整输出（禁只贴摘要） |
| 多案例糅合 | 多个真实案例融成一人设，不是只写一个人 |
| 序幕炸裂 | 全剧最抓人的一幕放开头，15-20 行演足，不铺垫 |
| 每幕 ≤20 行 | 只取冲突最尖的那一刻，不灌水 |
| 章节名一级标题 | `# 序幕` / `# 第一幕`，正文纯文本禁表格/加粗/引用 |
| 反派不降智 | 打脸靠程序/证据链，反派"自以为占理"，不靠巧合自爆 |
| 忠于事实 | 判决/数据/案件定性不编不改；法律/身份类事实权威核验 |
| 自动学习 | 你改过的稿子 AI 自动对比学习；说"全写入，改规则"直接固化 |

## 💡 使用技巧

### 技巧1：改稿就是喂经验（自动学习）
剧本交付后你改了任何部分，AI 会**自动对比初稿和你的修改版、提取经验写入经验库**。说一句 **"全写入，改规则"** 还能把经验直接升格为正式规则，下次写得更接近你的要求。

### 技巧2：糅合多个案例
跟 AI 说"糅合起来"，AI 会把多个真实案例的细节融成一个故事。核心事件忠于原型，外围细节可以重组。

### 技巧3：定题材基调
动笔前先告诉 AI 这次走**爽剧（艺术夸张、让普通人爽）还是纪实（还原真实、不夸张）**——同一个事件，两种口径写法完全不同。

### 技巧4：改文风方向
想长期改变文风（"以后不要那么压抑了""以后要加温情线"），跟 AI 说，它会定位现有规则、输出变更方案、修改文件，并清理经验库里的冲突经验。
