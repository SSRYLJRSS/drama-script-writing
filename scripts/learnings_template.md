# 自学习经验库（空白模板）

> 这个文件是AI的"活记忆"——每次剧本被用户修改后，AI会从中提取通用经验写入这里。
> 下次写剧本时，AI会先读这个文件，把经验用上。
> 文件有大小上限，超过阈值会自动压缩。

---

## 使用说明

- **AI读取时机**：每个新项目S0开始时，先读此文件摘要
- **AI写入时机**：**用户任何改稿/纠正后自动触发**——剧本交付后用户给出修改意见，AI改稿完成后立即对比初稿vs修改版提取经验写入（不依赖S5自检通过，不等用户喊S6）
- **快速升格通道**：用户说"全写入，改规则"/"以后就这样" → 经验**直接升格进 references 正式规则**，不留暂存区
- **压缩时机**：文件超过5KB或条目超过30条时，AI自动执行压缩
- **人工审核**：所有经验写入前必须经用户确认

---

## 经验格式

```
[日期] [项目类型] [维度]
- 观察：AI初稿和用户修改版之间发现了什么差异
- 规律：这个差异背后的通用规律（不是个例）
- 行动：下次写作时应该怎么做
- 置信度：高(已验证多次) / 中(验证1-2次) / 低(仅1次,待验证)
```

**写入规则**：
1. 只记通用规律，不记具体案例（案例存项目文件夹）
2. 只记AI常犯的错误和用户偏好的写法，不记显而易见的常识
3. 与SKILL.md现有规则重复的不记
4. 与SKILL.md核心规则冲突的→标记"需讨论"，不直接写入
