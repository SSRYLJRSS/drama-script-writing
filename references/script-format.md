# 剧本输出格式规范

> 剧本正文是**纯文本**，不是markdown排版。文件本身是.md但内容按纯文本写。**章节名（序幕/第一幕/第二幕…）用一级标题 `# 章节名`，正文禁表格/加粗/引用块。**

---

## 标准格式

```
{金句引言第一行}
{金句引言第二行}

# 序幕
场景：{地点}，{时间}
（{动作描写}）
{角色名}：{台词}
{角色名}：{台词}
（{动作描写}）

# 第一幕
场景：{地点}，{时间}
（{动作描写}）
{角色名}：{台词}

# 第二幕
场景：{地点}，{时间}
...

# 第X幕（尾声）
场景：{地点}，{时间}
（{画面描写}）
黑屏。字幕：
{真实案例1简述}
{真实案例2简述}
{真实案例3简述}
{最后一句话点题}
```

## 格式铁律

1. **章节名（序幕/第一幕/第二幕…）用一级标题 `# 序幕` / `# 第一幕`**，下一行直接"场景：地点，时间"，不空行。**只允许章节名使用标题符号，正文内禁止再出现任何 #**
2. **台词格式** `角色名：台词`（中文冒号或英文冒号均可，全篇统一）
3. **动作/画外音/镜头提示**用（括号），如 `（啪——耳光）` `（镜头下移）`
4. **电话那头/字幕/弹幕评论**也照台词格式处理
5. **正文禁**markdown表格、加粗、引用块、列表符号；金句引言和正文都不加markdown符号
6. **网友评论/弹幕必须用真实的**（真实热搜梗、真实评论区留言），禁编造网评

## 开头金句引言

两行，无标题，不加markdown符号。点题但不说教。

示例：
```
舞台越来越亮，她的世界越来越暗。
网络不是泄愤场，每句恶语都藏着重量。
```

```
你把真心捧给她，她把你明码标价。
闺蜜两个字，是这世上最好听的骗局。
```

## 场景切换

场景切换直接换行写新的"场景：xxx"，不空行，不加分割线。

## 角色名管理

### 核心规则：少而统一

1. **全文角色名≤3个**：主要角色控制在3个以内
2. **同一人只用1个称呼**：禁全名/英文艺名/昵称混用
   - ❌ "金善禹=Sunoo=善禹哥=力哥"中英混排
   - ✅ 统一用1个称呼
3. **路人角色无名化**：用"成员""同学A"代替名字
4. **粉丝群/群众用编号**：粉丝A/B跨幕复用，不新开C/D

### 人物名策略：剧内用网名，真名留两处

- **剧内统一用观众认知度高的网名/简称**
- **真名只保留在两处**：
  1. 角色表注明（"本名XXX"）
  2. 结尾字幕官方定性句（"官方确认XXX（本名）已于XX年遇害"）
- 绑匪/施暴者点名用网名更有冲击力

## 防封改名（交付标配）

AI短剧发布平台会对真实当事人姓名限流/封禁。**S4剧本交付前，真实人物名必须改近似防封名**。

| 原名 | 防封名 | 规律 |
|------|--------|------|
| 某明星A | 某明星B | 近似音替换 |
| 某网红C | 某网红D | 近似字替换 |

- 资料区注明"真实原型为XXX"便于溯源
- 新闻链接保留原名
- 不是可选优化，是**交付标配**

---

## 金额口径铁律

绑架/诈骗类案件，同一笔钱有**三套口径，严禁混写**：

| 口径 | 说明 | 写法 |
|------|------|------|
| **索要价** | 向家属索要的赎金总额 | "540万" |
| **实付价** | 家属实际支付的金额 | "80万，一分不少" |
| **抽成** | 诱骗者/中间人拿走的卖人钱 | "卖你的钱她早抽走了" |

**写任何金额前先问**：这是索要价？实付价？还是抽成？三笔钱各归各，数字对不上号=硬伤。

## 尸体处置/暴力场面

不演暴力画面，用**处置过程+自然音效**收幕：

```
（套进黑袋。拖走。）
（她闷喊：不要……求求你们……）
（切夜海船景。黑袋推进海——扑通。）
（水面恢复平静。）
黑屏。一行字：2023年6月，南海某海域。
```

水花+平静=压抑到顶。属于"核心事实外可重组的外围细节"，忠于"撕票+抛尸"定性即可。

## 资料区格式

剧本正文之后附资料区和新闻链接：

```
───────────────────
资料：
1. {事件简称}——{一句话概述}
来源：{媒体名称} {URL}

2. {事件简称}——{一句话概述}
来源：{媒体名称} {URL}
```

- 核心事实、判决结果、关键数据保持原封不动
- 每个案例附新闻链接
- 资料区与剧本正文用分割线隔开
